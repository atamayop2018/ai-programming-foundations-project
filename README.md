# AI Programming Foundations Project

## Project Description
This project demonstrates fundamental data analysis skills using Python and Jupyter notebooks. It involves cleaning, exploring, and visualizing Airbnb listing data from New York City to uncover market insights. The analysis includes data preprocessing functions, exploratory data analysis, and visualizations to understand pricing patterns and listing characteristics across different neighborhoods.

## What You Built
- Data cleaning functions for text and review columns
- Exploratory analysis function with summary statistics and correlations
- Three visualizations showing price distributions, neighborhood comparisons, and price-review relationships
- Comprehensive summary and interpretation of findings

## Dataset Used
**New York City Airbnb Open Data** - Available on [Kaggle](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

This dataset contains information about Airbnb listings in NYC from 2019, including pricing, location, host details, and review information.

## How to Run the Project

### Prerequisites
- Python 3.7+
- Jupyter Notebook

### Installation
1. Clone or download this repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Running the Notebook
1. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
2. Open `data_workflow.ipynb`
3. Run all cells in order

The notebook will load the data, apply cleaning functions, perform analysis, and generate visualizations.
